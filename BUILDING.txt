NearTalk v0.2 -- build instructions
=================================

Locally: Open the project in Android Studio using JDK 17, Android SDK 35, Gradle 8.11.1.
Build -> Build APK(s), or use a locally installed Gradle 8.11.1: gradle :app:assembleDebug
This source archive does not include generated wrapper scripts/JAR.

GitHub: Create a new repository, push all files including .github/workflows/build-apk.yml,
then run the "Build NearTalk Android APK" workflow from the Actions tab.

App output if successful: app/build/outputs/apk/debug/app-debug.apk

Do not treat the app as production-ready or secure until compiled and tested on two real phones.
See README.md, PUBLISH_TO_GITHUB.md, and HOW_TO_GET_APK.md.
